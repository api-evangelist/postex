# PostEx

> PostEx is a Pakistani e-commerce logistics, courier, and fintech platform offering cash-on-delivery fulfilment with instant upfront payments, a business suite, financing, and the XPay payment gateway. This llms.txt was generated by API Evangelist from the catalog and a live probe of the PostEx merchant Order Integration API (no provider-published llms.txt was found).

## APIs

- [PostEx Merchant Order Integration API](https://api.postex.pk/services/integration/api/order): Book shipments, list operational cities, retrieve merchant pickup addresses, track parcels, and list unbooked orders. Auth: merchant API token in the `token` request header.
